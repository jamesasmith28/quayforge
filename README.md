# QuayForge Studios website

Static public website. Upload the contents of this folder to the root of the public `quayforge` repository. Enable Pages: Settings → Pages → Deploy from a branch → main → /(root). No npm, game source, credentials, or Codemagic build needed.

The privacy pages are clearly marked pre-release and must not be treated as final App Store policies. Before launch confirm the operator's legal identity, applicable legal bases, retention/deletion and transfers for feedback (including any dashboard copies), Firebase security rules, consent messages/ATT and age audience, final SDK collection disclosures, and Midnight Merge's actual data flows. Confirm brand clearance before commercial release.

No analytics scripts or forms are included. Contact links use the studio's public Gmail address. Promotional images are illustrations, not game screenshots.
